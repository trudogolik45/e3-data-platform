# E3 Data Platform

Платформа, где пользователь загружает данные, собирает из готовых блоков граф обработки, запускает его и получает версионированный результат.

## Владение

**Organization**:
Группа проектов. Сама данными не владеет и доступа к своим Project не даёт.
_Avoid_: Tenant, компания

**Project**:
Единица владения и доступа: ей принадлежат датасеты, пайплайны и их запуски.
_Avoid_: Workspace, пространство

**Membership**:
Участие пользователя в Project с одной Role. Доступ к Project есть только через Membership; сам вход в систему доступа не даёт.
_Avoid_: Grant, permission, членство в Organization

**Role**:
Уровень доступа в Project: Viewer только читает, Editor ещё меняет данные и пайплайны, запускает и публикует, Admin ещё управляет Membership. Каждая следующая включает предыдущую.
_Avoid_: Permission, scope, группа

**Initiator**:
Пользователь, создавший PipelineRun. Публикация проверяет его Membership на момент Publication, а не на момент запуска.
_Avoid_: Owner, автор запуска

**Audit Event**:
Неизменяемая запись о том, кто в каком Project получил содержимое данных, создал или отменил PipelineRun, и было ли это разрешено. Не создаётся при чтении одних метаданных.
_Avoid_: Лог, event log, журнал событий

## Данные

**Dataset**:
Логическая коллекция данных проекта, у которой есть история версий.
_Avoid_: Таблица, файл

**DatasetVersion**:
Неизменяемый снимок данных датасета со своей схемой и порядковым номером внутри Dataset. Появляется только при загрузке или публикации.
_Avoid_: Snapshot, ревизия датасета

**Archived Dataset**:
Dataset, скрытый из обращения. В него нельзя загружать и публиковать, и новые запуски не могут его использовать. Уже созданные запуски, включая их публикации, и ссылки на его версии остаются рабочими. Из архива не возвращается.
_Avoid_: Удалённый датасет, deleted

**Upload**:
Загрузка сырого файла пользователем, которая после проверки становится DatasetVersion без вычислений.
_Avoid_: Import, ingest

**Publication**:
Явная операция, которая превращает NodeOutput в новую DatasetVersion существующего Dataset того же проекта. Происходит только в узле Publish Dataset.
_Avoid_: Commit, export, сохранение результата

## Вычисления

**Block**:
Готовый вычислительный шаг с контрактом входов, выходов и параметров, существующий в неизменяемых версиях. Регистрирует только команда платформы.
_Avoid_: Operator, task, step

**Pipeline**:
Граф из блоков, который пользователь собирает и редактирует.
_Avoid_: Workflow, DAG (как имя сущности)

**Archived Pipeline**:
Pipeline, скрытый из обращения. Его нельзя запускать, менять PipelineDraft и публиковать новые PipelineVersion. Уже созданные запуски остаются рабочими. Из архива не возвращается.
_Avoid_: Удалённый пайплайн, deleted

**PipelineDraft**:
Единственная изменяемая заготовка графа пайплайна. Запустить её нельзя, можно только опубликовать в PipelineVersion.
_Avoid_: Черновая версия, working copy

**Publish Dataset**:
Системный конечный узел пайплайна, привязанный к Output Slot. Только выход, подключённый к нему, публикуется как DatasetVersion.
_Avoid_: Sink, export node

**System Node**:
Узел пайплайна, который выполняет сама платформа, без Block и без ExecutionAttempt.
_Avoid_: Встроенный блок, internal step

**PipelineVersion**:
Неизменяемая версия графа пайплайна с порядковым номером внутри Pipeline. Каждый её блок закреплён за точной версией. Конкретные данные задаются только при запуске.
_Avoid_: Revision

**Input Slot**:
Именованный вход PipelineVersion, в который при запуске подставляется конкретная DatasetVersion.
_Avoid_: Параметр источника

**Output Slot**:
Именованный выход PipelineVersion, к которому при запуске привязывается существующий целевой Dataset.
_Avoid_: Target, destination

**Late Binding**:
Правило: PipelineVersion знает только слоты (возможно, со значениями по умолчанию), а итоговые входные версии и целевые датасеты определяются при запуске. «Последняя версия Dataset» по умолчанию превращается в точную DatasetVersion в момент создания PipelineRun.
_Avoid_: Параметризация пайплайна

**PipelineRun**:
Один запуск конкретной PipelineVersion. В момент создания фиксирует точные привязки всех слотов, и потом они не меняются.
_Avoid_: Job, execution

**Активный PipelineRun**:
PipelineRun в RUNNING или CANCELLING: его узлы работают или ещё останавливаются. У Project не больше 5 активных; остальные ждут в PENDING и стартуют в порядке создания.
_Avoid_: Работающий запуск, запуск в очереди

**Project Quota**:
Потолок CPU и RAM, которые одновременно заявили работающие ExecutionAttempt одного Project. Учитываются оба ресурса сразу; потолок общий для всех Project. NodeRun, которому не хватает квоты, ждёт в PENDING, и попытка для него не создаётся: это не ошибка и не тратит попыток. Ждущие узлы получают место по порядку создания их PipelineRun. Квота считает заявленный размер, а не фактическое потребление, и не обещает, что кластеру хватит мощности.
_Avoid_: Лимит ресурсов, ResourceQuota (это объект Kubernetes)

**NodeRun**:
Логическое выполнение одного узла внутри PipelineRun. Успешно завершается в SUCCEEDED и имеет не более одного принятого результата.
_Avoid_: Execution, job, task run

**ExecutionAttempt**:
Одна физическая попытка выполнить NodeRun. Попыток может быть несколько, результат принимается только от одной.
_Avoid_: Retry, try

**Current Attempt**:
Единственная ExecutionAttempt, которую Run Orchestrator назначил для NodeRun сейчас. Только её результат может быть принят, и других активных попыток у этого NodeRun нет.
_Avoid_: Последняя попытка, активная попытка

**Lost Attempt**:
ExecutionAttempt, итог которой неизвестен и уже не может стать известен, при этом доказано, что она не выполняется и не возобновится.
_Avoid_: Зависшая попытка, timeout, failed

**Reconciliation**:
Сверка состояния попытки, которое помнит Run Orchestrator, с тем, что реально происходит в Execution Plane. Запускается, когда о попытке давно нет вестей. Сама по себе ничего не доказывает.
_Avoid_: Health check, heartbeat

**Attempt Fence**:
Запрет на запуск конкретной ExecutionAttempt, который ставит Execution Controller, прежде чем объявить её Lost Attempt или отменённой. Опоздавшая команда на эту попытку уже ничего не запустит.
_Avoid_: Блокировка, tombstone, надгробие

**Attempt Credentials**:
Краткоживущие S3-ключи одной ExecutionAttempt: читают только её входы и пишут только в её выход. Выдаёт их Execution Controller; после срока жизни они не работают, досрочно не отзываются.
_Avoid_: S3-ключи блока, временный доступ, токен попытки

**Fail-fast**:
Правило PipelineRun: как только NodeRun окончательно упал, новые узлы не запускаются, активные отменяются, ожидающие пропускаются. Запуск завершается FAILED лишь после доказанной остановки всех узлов и помнит упавший узел как первопричину.
_Avoid_: Аварийная остановка, abort

**Cancellation**:
Запрос пользователя остановить PipelineRun. Это не мгновенный итог: запуск становится CANCELLED лишь после доказанной остановки всех узлов, а начатые проверка результата и публикация доделываются. Начатый Fail-fast отмена не перебивает.
_Avoid_: Abort, kill, прерывание

**NodeOutput**:
Принятый логический выход NodeRun в состоянии READY, определяемый парой NodeRun и порт. Только его потребляют downstream-узлы.
_Avoid_: Промежуточный датасет, результат

**Manifest**:
Опись данных NodeOutput или DatasetVersion: файлы, формат, схема, объём и контрольные суммы. Формат у обоих общий.
_Avoid_: Metadata file, index

**Artifact**:
Физический объект в хранилище: файл данных, manifest, лог.
_Avoid_: Output, результат
