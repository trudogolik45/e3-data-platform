# Публикация только через System Node Publish Dataset, сразу и без отката

Результат вычисления не становится DatasetVersion автоматически. Публикация — явный конечный System Node `Publish Dataset`, привязанный к Output Slot (Late Binding, целевой Dataset задаётся при запуске или берётся по умолчанию). Его выполняет Dataset Catalog внутри Control Plane, без Spark и Execution Controller. Публикация происходит сразу, как только готов upstream-узел, не дожидаясь всего DAG. Уже опубликованные версии не откатываются, даже если PipelineRun потом упал или отменён: DatasetVersion неизменяема. Начатую фиксацию отменить нельзя.

## Considered Options

- Публиковать каждый выход каждого узла: каталог забивается промежуточным мусором.
- Публиковать все выходы в конце запуска («всё или ничего»): отказались ради скорости появления результатов. Цена — возможна частичная публикация.

## Consequences

- Промежуточные результаты — NodeOutput в staging, а не DatasetVersion. Неопубликованные данные хранятся 7 суток, диагностические Artifact'ы — 30 суток после завершения PipelineRun.
- Права на запись проверяются дважды: при создании PipelineRun и прямо перед публикацией.
