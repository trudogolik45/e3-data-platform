# Модульный Control Plane и отдельный Execution Plane

E3 строится как модульный монолит на FastAPI (Control Plane) и отдельно развёртываемый Execution Plane (Execution Controller и Spark on Kubernetes). PostgreSQL — источник истины для метаданных и состояний, Kafka — транспорт только для команд и событий между плоскостями, S3 — канал обмена данными между вычислениями. Так меньше распределённой связанности, жизненным циклом управляют из одного места, а вычисления масштабируются независимо.

## Consequences

- Внутри Control Plane модули общаются через Python-интерфейсы, а не через Kafka RPC. Чужие таблицы напрямую не пишут.
- Вычислительные задачи не имеют доступа к PostgreSQL Control Plane.
- Состояние и команда записываются атомарно через transactional outbox, события дедуплицируются через inbox, пропуски закрывает reconciliation.
